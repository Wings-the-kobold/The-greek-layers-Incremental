# Queued Upgrades to Heliosphere Check
    ah, welcome to the randomizor! a rng mechanic solely based on your luck!
    note that every usage spends your AP! but don't worry too much on that because there is an anti-softlock protection feature that prevents you from using them all!

    there are three new things you should track, and only that during this section,
    CRNG (Current Randomized Number Generations) - Your current RNG that was generated from the machine
    TRNG (Totalled Random Number Generation) - Combined CRNG from all rolls, like adding CRNG's together
    BRNG (Banked Random Number Generations) - Stores the best possible RNG obtained ever.

        also new strategy for farming for Aperativity, where you prioritize Dark Checks over Light Check. this is because Dark check is still slow and should be taken care of first
        You also do not need to progress much in Light Checks, 
 ` DK[1,2,3,4] `, `LK[1,2,3,4,5,6]`, `DK[5,6]`.
        this is until you get Replication, then you can do whatever you want.
    
    Prioritize Quantify over Ransial, and Elevate over Replication

    Although i'd only recomend Getting good enough levels of Quantify AND Elevate to make Replication grind easier
    i would NOT recomend going for Replication immediately, since it is not worth the grind before having any bonuses
    
    you should push for SR Cap if needed, it could help ALOT in later Aperativity grinds.
